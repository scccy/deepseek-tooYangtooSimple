# Vendored Speckit Skills

These 10 `SKILL.md` files are vendored from
[github.com/github/spec-kit](https://github.com/github/spec-kit) (MIT License,
© GitHub, Inc.), as generated by the `specify` CLI v0.16.4 in Codex skills
mode (`specify init --here --integration codex --integration-options="--skills"`).

| Skill directory | Workflow phase |
|---|---|
| `speckit-specify` | specify |
| `speckit-worktrees-create` | worktrees |
| `speckit-clarify` | clarify |
| `speckit-plan` | plan |
| `speckit-checklist` | checklist |
| `speckit-tasks` | tasks |
| `speckit-analyze` | analyze |
| `speckit-taskstoissues` | taskstoissues (optional) |
| `speckit-implement` | implement |
| `speckit-converge` | converge |

`speckit-constitution` and `speckit-worktrees-clean/-list` are intentionally
not vendored: the constitution is out of the chain and the worktrees cleanup
/list commands are interactive maintenance tools, not pipeline phases.

At run start the plugin materializes these files under the target project's
`.dsh/speckit-workflow/skills/` (hash-verified, re-synced on plugin upgrade),
so phase agents read skills from a stable project-relative path — never from
the package's install location and never from a project-local `.agents/skills`
installation, which is no longer required.
