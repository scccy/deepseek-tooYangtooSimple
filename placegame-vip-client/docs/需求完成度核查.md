## 小号 Boss 爬梯 v2（2026-08-28，替代原"锁定当前挂机地图"策略）

> 用户确认的策略调整：小号目标是**爬梯子升级**（打 boss 拿装备 → 穿上 → 打下一个级别），
> 10/10 套装统计不作为决策依据；大号 Boss 逻辑不动（用户手动刷）。

- 梯子：个人/地图首领按战力升序排（同战力按等级/地图/key）；每号梯位持久化在 `boss_farm.current_boss_key`
- 每日链式推进：打当前 boss 免费次数（难度锚 = 已记录最高可胜 +1 向上爬，preview 实测赢才 challenge）
  → 每赢一场**立刻换装**（auto_equip_best，解决"打完没穿新装备"）→ 全部位毕业 + 下一个 boss preview 可胜 → 梯位+1
- 打不赢当前梯位：向下修正到**实测能赢的最高 boss**（不空转、不一路掉到最低）
- 词缀自动：按 `challengeOptions.affixes[].rewardMultiplier` 降序试，打实测能赢的最高奖励配置；材料加成默认开（不支持自动降级）
- 毕业：该 boss **最高难度**打赢且掉落含该部位 → 写 SQLite 新表 `boss_graduate(account_id, boss_key, slot)`；轮换只刷未毕业部位（缺优先→品质低→高）
- 0 场：免费次数用完/全部位已毕业 → Ok 收工；否则 Err 走退避重试（当天不锁死）
- 配套修复：挑战胜负按响应内容判定（`challenge_won` 多候选+notices 文案，未识别按 HTTP 成功兜底）；`boss_progress.best_index` 仅胜利写入（失败不污染）；单次 run 内 preview 结果缓存（换装后失效）
